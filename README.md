# 고1 아들과 함께한 테트리스 게임

이 레포지토리는 **바이브코딩**으로 고1 아들과 함께 만든 테트리스 게임입니다.

## 우리가 한 일
1. GitHub에 새 레포지토리 만들기
2. AI(Grok)에게 테트리스 게임 코드 요청해서 받기
3. `index.html`에 완전한 테트리스 게임 올리기
4. GitHub Pages로 인터넷에 공개

## 게임 주소
**https://ocusun.github.io/son-test-page/**

## 조작법
- ← → : 좌우 이동
- ↑ : 회전
- ↓ : 빠르게 내리기
- Space : 한 번에 내리기
- P : 일시정지
